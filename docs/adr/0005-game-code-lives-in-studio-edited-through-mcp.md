# Game code lives in Studio, edited through the MCP

Game code is hosted in the Studio place and edited through the Roblox MCP, while design docs live in this git repository. A future reader may expect a local-source workflow such as Rojo, which was considered and not chosen, so code history comes from Roblox version history rather than git. This is why [code structure](../code-structure.md) has safeguards for published checkpoints and small, focused edits.

If Studio-only source becomes a meaningful limitation, moving to a local-source workflow can be reconsidered. Do not introduce that tooling just because it might be wanted later.
